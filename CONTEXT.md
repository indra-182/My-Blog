# INDRA.DEV Blog

This context names the blog's content boundaries and the language used for its reading experience.

## Language

**Editorial content**:
The author-managed material that makes up a post, including its body and descriptive metadata. Editorial content remains unchanged when site copy is refreshed.
_Avoid_: UI copy, site metadata

**UI copy**:
Reader-facing labels, actions, descriptions, and accessibility text that explain or operate the blog outside editorial content.
_Avoid_: post content, editorial metadata

**Site metadata**:
Static titles, descriptions, social-preview text, and feed descriptions that describe INDRA.DEV as a site rather than an individual post.
_Avoid_: post metadata, editorial metadata

**Footer parity**:
The blog footer follows the sibling portfolio's structure, visual behavior, and language while retaining the blog's cross-project navigation destinations.
_Avoid_: portfolio-only content
